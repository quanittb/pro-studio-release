# Pro Studio AI

Đây là kho lưu trữ các bản phát hành chính thức của **Pro Studio AI**.

## Tải về

Vào mục **[Releases](../../releases)** để tải phiên bản mới nhất.

- Pro Studio AI Setup *.exe — Trình cài đặt (khuyến nghị)
- Pro Studio AI *.exe — Phiên bản portable (không cần cài)

## Cập nhật

Ứng dụng sẽ tự động kiểm tra và thông báo khi có phiên bản mới.
Bạn cũng có thể kiểm tra thủ công trong **Cài đặt → Ứng dụng → Kiểm tra cập nhật**.

## Phiên bản

Xem file [ersion.json](./version.json) để biết phiên bản hiện tại.
